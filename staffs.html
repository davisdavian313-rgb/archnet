ARCHNETWORK — Staff Quick Reference

Clear, color-coded duties for each role. Use search or filters to jump to what you need.

Owner Admin Moderator Builder Developer Event Helper Trainee
👑
Owner / Co-Owner
Leadership
  • Oversee network and servers
  • Approve staff and major updates
  • Manage finances and partnerships
  • Ensure community growth
🛡
Sr Admin
Administration
  • Lead the admin team and manage staff hierarchy
  • Enforce rules for serious incidents
  • Oversee server updates and plugins
  • Approve promotions and major staff actions
  • Act as main point of contact for the Owner
🛡
Jr Admin
Administration
  • Assist Sr Admins with moderation and staff oversight
  • Enforce rules and handle moderate incidents
  • Support server updates and plugin testing
  • Mentor Sr/Jr Moderators and Moderators
  • Report important issues to Sr Admins
✨
Sr Moderator
Moderation
  • Lead the moderation team and guide Jr Mods
  • Handle complex player disputes and serious violations
  • Oversee chat and gameplay moderation
  • Assist Admins in enforcing server policies
  • Train Moderators
✨
Jr Moderator
Moderation
  • Assist Sr Mods and Admins with moderation
  • Monitor chat and player behavior
  • Handle minor warnings, mutes, kicks
  • Report serious incidents to Sr Mods or Admins
  • Support Moderators and community guidance
✨
Moderator
Moderation
  • Monitor chat and player behavior
  • Warn, mute, kick, ban as needed (following rules)
  • Handle player reports and guide new players
  • Keep community friendly and welcoming
🏗
Builder
World Design
  • Build and maintain server areas
  • Design functional and aesthetic structures
  • Repair and improve existing builds
💻
Developer
Engineering
  • Maintain and develop plugins
  • Test for bugs and optimize server
  • Implement custom items and features
🎉
Event Manager
Community Events
  • Plan and run events
  • Coordinate with staff
  • Promote events and gather feedback
🤝
Helper
Support
  • Assist new players
  • Answer questions and guide gameplay
  • Report rule-breaking and support events
🌱
Trainee
Onboarding
  • Learn the rules, server systems, and staff responsibilities
  • Assist Mods, Admins, Builders, or Event Managers with small tasks
  • Observe moderation and staff procedures
  • Work toward promotion to full staff role

Tip: Use the search bar to find specific duties (e.g., “plugins”, “events”, “ban”). Click a filter chip to narrow roles.
